# Security Policy

## Reporting a vulnerability

Please do **not** disclose exploitable vulnerabilities, credentials or private user/customer data in public issues or pull requests.

Report privately to **[contato@vytetech.com](mailto:contato@vytetech.com)** with a clear subject such as `Security report — GitHub repository`.

Include affected repository, impact, reproduction steps and contact information where feasible. We will assess each report and coordinate remediation.

No bug bounty program or guaranteed response timeframe is implied by this policy.

## Supported projects

Support scope depends on the individual repository and the applicable maintenance agreement. Check repository documentation before assuming active support.

## Disclosure

Please allow time for triage and remediation before public disclosure.
